AEV API Test UI

Einfaches Test-Frontend für deine AEV-Controller Endpunkte.

Basis

Fehler testen & Payloads

Fülle schnell typische Fehlerfälle vor, um die Fehlerrückgaben der API zu prüfen, oder nutze die Beispiel-Payloads als Vorlage zum Schreiben in der DB.

Fehlersimulation

Setze die API absichtlich unter ungültige Bedingungen und beobachte die Responses.

Payload-Bibliothek

Übernimm gültige Beispiel-Requests und passe sie an, um Daten in die Datenbank zu schreiben

Diese Bodies enthalten bereits Felder für DB-Schreibzugriffe (SOLL-Werte,Status,Quellenangabe, usw.).
